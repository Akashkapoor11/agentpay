# PayPal AI Hackathon — compliance map

This is a technical preparation document, not a legal eligibility determination. The entrant must confirm the latest official rules, eligibility, original-work declarations and final submission details.

| Requirement | AgentPay evidence / remaining entrant action |
|---|---|
| Meaningful PayPal + AI | OpenAI Responses API plus PayPal Sandbox Orders v2 create/approval/capture flow. Demonstrate the live Sandbox flow before submitting. |
| PayPal central to product | PayPal is the final payment rail; server-side order creation and capture are guarded by the signed mandate. |
| Functional demo | A real working build must be hosted or reproducibly runnable from the repository. A screenshot/mockup is insufficient. |
| Repository | Publish all source, assets and instructions to a public GitHub/GitLab/Bitbucket repository. |
| Open-source license | Root-level MIT `LICENSE` is included; verify the published repository displays it. |
| Demonstration video | `DEMO_SCRIPT.md` is 2:55; entrant must record and upload a real under-three-minute YouTube video with public visibility. |
| English | README, project description and demo instructions are in English. |
| Third-party services | Entrant must comply with PayPal, OpenAI, Channel3, Render and package licenses/terms. |
| Existing-project rule | Project archive shows it was built during the hackathon window; entrant must accurately declare project creation/progress and ownership. |
| Judge testing | Provide working URL or complete setup instructions and any necessary Sandbox test credentials/instructions. Keep access free and available for the judging period. |
| Sponsor prizes | Select sponsor categories only after the corresponding tool is genuinely used and the sponsor-specific requirements are met. |

## Claims to avoid

- Do not claim official PayPal AP2 implementation, AP2 compliance, certification, partnership or endorsement.
- Do not claim real merchant trust, sustainability certification, live local-catalogue inventory or guaranteed delivery; the checkout catalogue is synthetic.
- Do not claim Channel3 observations are like-for-like market benchmarks without a verified product match.
- Do not describe local smoke tests as proof of a successful live PayPal transaction.
- Do not claim Render, PayPal MCP, AG Studio or a sponsor integration is live unless it is configured and demonstrated in the submitted build.
