# AP2 / Mandate positioning note

PayPal has publicly discussed the Agent Payments Protocol (AP2) as a framework for verifiable, auditable agent-driven payments. Its public description includes intent mandates, cart mandates and payment mandates.

AgentPay should say:

> “Inspired by the trust and verifiable-intent direction PayPal describes for agentic payments.”

AgentPay should **not** say:

- “Official AP2 implementation”
- “AP2 compliant”
- “PayPal certified”

AgentPay does not make any of those claims.

The hackathon requirement is PayPal developer platform + AI; the prototype satisfies that requirement through PayPal Sandbox Orders v2 and AI tool calling.
