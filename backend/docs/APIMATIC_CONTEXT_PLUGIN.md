# APIMatic Context Plugin — Required Provenance Step

The hackathon sponsor opportunity is for participants who actually use APIMatic Context Plugin for PayPal while building the integration. This cannot be truthfully simulated by adding an npm package.

Before submission:

1. Use APIMatic Context Plugin in the AI coding environment.
2. Ask it for PayPal API context while reviewing or implementing the Orders v2 create/capture path.
3. Apply at least one meaningful improvement informed by that context.
4. Keep any available context/transcript evidence.
5. Set `APIMATIC_CONTEXT_USED=true` only after steps 1–4 are true.

Never select the APIMatic sponsor option on Devpost merely because this file exists.
